# 디맥 판정 분석기 (DmJudge)

**DJMAX RESPECT V**를 플레이하는 동안, 노트 하나하나를 **몇 ms 빨리/늦게 쳤는지** 실시간으로 보여주는 프로그램입니다.

- 기어 위에 반투명 **인디케이터**를 띄워서, 키를 누르는 순간 영점에서 얼마나 벗어났는지 바로 보여줍니다.
- 플레이 기록으로 나에게 맞는 **판정 타이밍(눈판정)** 과 **출력 타이밍(귀판정)** 을 추천합니다.
- 곡이 끝나면 **결과 화면 숫자를 자동으로 읽어서** 분석기의 영점을 게임에 맞춰 줍니다.

> 비공식 팬 메이드 도구입니다. NEOWIZ / DJMAX 공식과 관련이 없습니다.

---

## 안전한가요?

- **게임 메모리를 읽지 않고, 게임 파일도 건드리지 않습니다.**
  쓰는 건 딱 두 가지예요: **화면 캡처**(녹화 프로그램과 같은 방식)와 **키 입력**(어떤 키를 언제 눌렀는지).
- 키 입력은 내 PC 안에서 노트와 짝짓는 데만 쓰고, **어디로도 보내지 않습니다.** 분석기는 인터넷을 쓰지 않아요.
  (설치할 때만 파이썬과 부품을 받느라 인터넷을 씁니다)
- 소스 코드가 전부 여기 공개되어 있습니다.
- exe를 따로 배포하지 않고, 공개된 소스를 **내 PC에서 공식 파이썬으로 그대로 실행**합니다.
  그래서 출처를 알 수 없는 exe를 믿고 실행할 필요가 없어요.
- 처음 `INSTALL.bat` 을 실행할 때 Windows가 "PC 보호" 경고를 띄울 수 있어요(인터넷에서 받은 파일이라서). **추가 정보 → 실행** 을 누르면 됩니다.

## 설치 (처음 한 번, 5~10분)

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **Download ZIP**
2. 받은 zip 파일을 오른쪽 클릭 → **압축 풀기** → 원하는 곳(예: 바탕화면)에 풀기
3. 풀린 폴더 안의 **`INSTALL.bat`** 더블클릭
   - 파란 창 "Windows의 PC 보호"가 뜨면 → **추가 정보** → **실행**
   - 검은 창이 알아서 다 해요: 파이썬이 없으면 자동 설치 → 필요한 부품 설치 → **바탕화면에 `DmJudge` 바로가기**
   - 다 되면 "설치 끝!"이 나오고, 엔터를 누르면 분석기가 켜져요.
4. 다음부터는 **바탕화면의 `DmJudge`** 를 더블클릭하면 돼요.

> 설정과 기록은 **압축을 푼 그 폴더**에 저장돼요(config.json, results.json, CSV). 폴더를 지우지 마세요.
> 설치가 실패하면 그 검은 창을 사진으로 찍어 **Issues**에 올려 주세요.

### 새 버전으로 업데이트
1. 위와 같이 **Download ZIP** 으로 새로 받기
2. 압축을 푼 파일을 **원래 폴더에 덮어쓰기** (설정·기록은 그대로 남아요)
3. **`INSTALL.bat`** 한 번 더 더블클릭 (이번엔 금방 끝나요)

## 처음 설정 (한 번만)

1. 디맥을 **보더리스 창** 으로 켭니다. (설정 → 화면 모드. 전체 화면 독점 모드는 캡처가 안 될 수 있어요)
2. 곡을 고르고, 노트가 아직 안 나온 **곡 시작 직전 화면** 에서 멈춥니다. (일시정지 화면도 OK)
3. 분석기에서 **[영역 보정]** 을 누릅니다.
   - 마우스로 **플레이 영역을 드래그**: 1번 레인 왼쪽 끝 ~ 마지막 레인 오른쪽 끝, 위쪽 ~ 판정선까지 → **Enter**
   - 빨간 선이 **판정선 한가운데** 오도록 `W` / `S` (`A` = 자동 찾기) → **Enter**
4. **[미리보기]** 를 눌러 노트에 초록 테두리가 따라가는지 확인합니다. (닫기: `ESC`)
5. 게임에서 쓰는 **판정 타이밍 / 출력 타이밍** 값을 분석기 위쪽 칸에 똑같이 적습니다.

끝! 이제 그냥 플레이하면 됩니다. 4B / 5B / 6B / 8B는 자동으로 알아봅니다.

## 이렇게 쓰세요

| 하고 싶은 것 | 방법 |
|---|---|
| 내가 빨리 치는지 늦게 치는지 보기 | 플레이 후 **"나만의 판정선"** 숫자 (−면 빠름, +면 느림) |
| 판정 타이밍 추천 받기 | 소리 끄고 정박 곡 몇 곡 → **"추천 판정 타이밍"** |
| 귀판정(출력 타이밍) 추천 받기 | 설정에서 **귀판정 측정** 선택 → 화면 안 보고 소리에만 맞춰 쉬운 곡 → **"추천 출력 타이밍"** |
| 분석기 영점을 게임에 맞추기 | 곡을 **결과 화면까지** 끝까지 치기 (3곡 이상 모이면 자동 추천) |
| 곡마다 새로 재기 | 곡 시작 전에 **[초기화]** |

인디케이터는 **[인디케이터 이동]** 으로 원하는 위치에 끌어다 둘 수 있어요. 마우스 휠 = 막대 폭.
평소에는 클릭이 그대로 통과해서 게임에 영향이 없습니다.

### 스킨 옵션 (해당될 때만 켜기)
- **어두운 노트 스킨**: 어둡거나 반투명한 노트
- **동그란 노트 스킨**: 고리(테두리) 모양 동그란 노트
- **판정 이펙트가 큰 스킨**: 판정선 위로 높이 솟는 판정 이펙트(캔 모양 등)
- 기어(패널) 스킨을 바꾸면 **[영역 보정]** 을 다시 해 주세요.

자세한 설명은 **[MANUAL.txt](MANUAL.txt)** 에 있습니다.

## 문제가 생기면 (제보 방법)

1. 분석기에서 **[초기화]** → 문제가 생긴 곡을 한 번 **결과 화면까지** 칩니다.
2. **[CSV 저장]** → 파일 2개가 생깁니다: `이름.csv`, `이름_raw.csv` (기본 저장 위치는 프로그램 폴더)
3. 이 페이지 위쪽의 **Issues** → **New issue** → 양식에 맞춰 적고 **두 파일을 끌어다 놓아 첨부** 합니다.
   - 가능하면 그 판의 **녹화 영상** 도 같이 (화면 녹화 프로그램 아무거나, 인디케이터는 기어 밖으로)
   - 폴더에 `dumps` 폴더나 `error_log.txt` 가 생겼다면 그것도 같이 주시면 큰 도움이 됩니다.

## 개발자용

- 소스 그대로 실행됩니다(별도 빌드 없음). `INSTALL.bat` → `install.ps1` 이 폴더 안에 `.venv`(Python 3.10 이상)를 만들고 `requirements.txt`를 설치한 뒤, `.venv\Scripts\pythonw.exe main.py` 바로가기를 만듭니다.
- 오류 메시지를 보면서 실행: **`run_dev.bat`** (검은 창). 바로가기로 실행하다 오류가 나면 폴더에 `error_log.txt` 가 남습니다.
- 바로가기 없이 실행: **`START.bat`**
- 사용 라이브러리: numpy, opencv-python, dxcam, pillow
- exe가 필요하면: `.venv\Scripts\python -m pip install pyinstaller` 후
  `.venv\Scripts\python -m PyInstaller --onefile --noconsole --name DmJudge --collect-all dxcam main.py`
